# A 股选股分析平台

一个面向个人投资者的 A 股数据同步与技术分析平台，支持 K 线图展示、多维度技术指标计算、选股策略筛选与单股回测。

> **平台说明**：Python / Node 代码本身不含平台相关逻辑；仅 `Makefile` 里写的是 `python.exe` / `npm.cmd`，只能在 Windows 下用。其他平台请用下方的手动启动命令。

## ✨ 核心功能

| 功能模块 | 说明 |
|---------|------|
| **数据同步** | 从腾讯财经 API 同步全市场 A 股前复权 K 线，拉取与入库并行流水线 |
| **技术指标** | MA 均线（5/10/20/30/60）、布林带、MACD（DIF/DEA/柱状图） |
| **K 线图** | 基于 TradingView lightweight-charts，Canvas 渲染，缩放平移丝滑，主图/MACD 双窗格联动 |
| **选股策略** | 内置 4 套策略，参数可调，一键筛选全市场；插件式架构，新增策略只需加一个文件 |
| **单股回测** | 对指定股票重放策略，列出历史全部买点并在 K 线图上标记 |
| **数据管理** | 单股 / 全量数据清理，跳过列表管理，独立补算脚本 |

## 🚀 快速开始

### 环境要求

- **Python**：3.8 及以上
- **Node.js**：16 及以上

### 启动方式

**Windows（需安装 Make）：**

```bash
make bk   # 启动后端
make fe   # 启动前端（新开一个终端）
```

**手动启动（全平台）：**

```bash
# 后端
cd backend
pip install -r requirements.txt
python run.py

# 前端（新开一个终端）
cd frontend
npm install
npm run dev
```

### 访问地址

- **前端页面**：http://localhost:5173
- **后端 API**：http://127.0.0.1:8001
- **API 文档**：http://127.0.0.1:8001/docs

### 首次使用

1. 打开前端页面，进入「数据同步」页面
2. 点击「同步基本信息」同步股票基本资料（市值、PE 等）
3. 选择日期范围，点击「开始同步」下载 K 线数据
4. 同步完成后，进入「股票列表」查看和筛选股票，点击「K线」看个股图表
5. 进入「选股策略」页运行全市场筛选，或对单只股票做历史回测

> 首次同步耗时较长：受腾讯 API 限流约束（4 次/秒），全市场约 2000 只股票需要较长时间，页面会显示实时进度。

## 📊 技术指标说明

| 指标 | 参数 | 说明 |
|------|------|------|
| MA 均线 | 5/10/20/30/60 日 | 简单移动平均线 |
| 布林带 | 20 日，±2 倍标准差 | 基于 MA20 的通道指标 |
| MACD | 12, 26, 9 | DIF、DEA、MACD 柱（`2×(DIF−DEA)`） |

## 📈 内置选股策略

| 策略 | 逻辑 |
|------|------|
| 跌破布林下轨后连续站 MA5 | 近 x 天内跌破布林下轨，之后 y 天内连续 z 天收盘价站上 5 日均线 |
| 大涨后连续下跌 | 近 x 天内出现涨幅 > y% 的交易日，之后连续 z 天收盘价下跌 |
| 站上 60 日均线 | 最近 y 天内有 z 天收盘价站上 60 日均线 |
| MACD 绿柱拐点上升通道 | MACD 绿柱波段见底后连续缩短确认，且本波最低价高于上一波最低价 |

## ⚠️ 注意事项

1. **单机单用户**：无用户认证、无分布式支持；后端必须单进程运行（同步状态存于进程内存）
2. **数据源限制**：腾讯财经 API 有频率限制，同步已内置全局限流
3. **市值单位统一为亿元**：`total_cap` 及所有市值筛选入参均为亿元
4. **前复权数据会变**：除权除息后历史价格会整体调整，同步时会自动识别并对受影响的股票重拉全部历史
5. **数据仅供参考**：所有指标与策略仅供学习研究，**不构成投资建议**
6. **数据库文件**：SQLite 位于 `backend/data/stock.db`，建议定期备份
